NSC Raw Excel Upload

How to upload
  1. Select the data / report date (as-on date of the Excel). This becomes Updated on on the Pending NSC dashboard.
  2. Choose the raw Malda Zone pending NSC file (.xlsb, .xlsx, or .csv).
  3. Click Upload & Publish. The file is cleaned in your browser first (large files stay under the live-server size limit), then only Working/Accepted rows are published.
  4. Open the NSC dashboard and refresh if needed to see the new data.

Only Working and Accepted applications are published. Withheld rows are skipped automatically.

Admin view: cleaned rows publish to Supabase (with local backup). Dashboards read via DataHub cache. Grant upload rights under Admin → User Management → NSC Raw Upload.

Use the as-on date of this Excel dump. Delay days are calculated from this date.
