NSC Upload

How to upload
  1. Select the data date (as-on date of this NSC file).
  2. Choose the pending NSC Excel file (same SAP dump).
  3. Click Upload & Publish and wait until both datasets finish.
  4. Open the NSC and Withheld dashboards to verify.

Same as before: you upload the raw SAP Excel. The page processes it (DETAILS sheet, status split, division cleanup, delay columns), then inserts the cleaned rows — Working/Accepted → nsc_working, Withheld → NSCWH Sheet1. Raw extra SAP columns are not copied.

Same pipeline as the old Supabase insert: raw file → process → cleaned 45-column rows. Destination is Google Sheets. A small version record is still stored so dashboards show “Updated on”. Grant rights under Admin → User Management → NSC Raw Upload.

Use the as-on date of this Excel. It appears as “Updated on” on both dashboards.
